# Snova Strings (`Snova.Std.Strings`)

String utilities and builders in pure Snovalang.

## Features
- `StringUtils` (`parseInt`, `intToString`, `split`, `join`, `padLeft`, `padRight`)
- `StringBuilder` for high-performance string concatenation
